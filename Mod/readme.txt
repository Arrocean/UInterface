UInterface

UInterface is a foundation mod for UBOAT. It provides submarine registration,
equipment mounts, crew stations, and optional interfaces for equipment and
subsystems. Submarine, equipment, and campaign creators publish their content
as separate mods.

Enable UInterface in UBOAT's Mods tab before playing content that requires it.
The game compiles the C# source in this package. The Reflection permission
enables integration with the original game and other loaded mods.

Source and integration guide
https://github.com/Arrocean/UInterface
